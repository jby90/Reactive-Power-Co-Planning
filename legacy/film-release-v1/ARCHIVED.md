# Archived FiLM release

This directory preserves the repository's first public release, which was organised around FiLM-PPO and an earlier capacity-planning narrative. It is retained for provenance only.

The current manuscript, headline results, and recommended reproduction workflow use WG-CVaR-PPO with AC safety projection and are documented in the repository root. Files under this archive must not be mixed with the current `data/`, `models/`, or `figures/` directories when reproducing the submitted study.
